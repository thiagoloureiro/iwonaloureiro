# Site Contact Skill

Retrieve public contact information for Iwona Loureiro Studio.

## Usage

Call `GET https://ilstudio.design/api/v1/contact` or use the WebMCP `get_contact_info` tool on the homepage.

## Response fields

- `studio` — Studio name
- `email` — Contact email
- `linkedin` — LinkedIn profile URL
- `website` — Canonical site URL
