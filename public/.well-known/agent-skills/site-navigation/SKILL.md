# Site Navigation Skill

Navigate the IL Studio website and discover available pages.

## Pages

| Path | Description |
| ---- | ----------- |
| `/` | Homepage with interactive menu |
| `/projects` | Design portfolio |
| `/about` | About the designer |
| `/services` | Service offerings |
| `/contact` | Contact information |

## Usage

Use the WebMCP `navigate_to` tool with a path parameter, or request markdown versions via `Accept: text/markdown`.
